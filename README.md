# SopSnap

Drop screenshots in order. Get a one-file HTML SOP. Files never leave the browser.

Ask this answers: [Looking for a Scribe alternative that is easy to maintain](https://www.reddit.com/r/software/comments/1vkg1d9/looking_for_a_scribe_alternative_that_is_easy_to/)

- No account
- No upload
- Cap: 12 files, 8 MB each
- PNG, JPEG, WebP
- One `.html` you can email, keep in git, or edit in a text editor
- Filenames become step titles

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```

This does not capture clicks. You still take the screenshots.
